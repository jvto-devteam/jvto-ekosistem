# Data Intake Plan

Use this order when adding new data.

## Step 1: Identify Domain

Classify each new piece of data into one primary core:

- Knowledge & Evidence
- Product & Commercial
- Booking & Journey
- Operations
- Experience Engine

## Step 2: Identify Stability

Mark whether the data is:

- static: safe as versioned files;
- dynamic: should become database-backed;
- generated: should be produced from another source.

## Step 3: Identify Owner

Use one owner per fact or contract:

- company;
- legal;
- operations;
- editorial;
- commercial;
- finance;
- customer support.

## Step 4: Identify Consumers

List where the data is used:

- public website;
- SEO metadata;
- JSON-LD;
- knowledge feed;
- WhatsApp;
- email;
- quote;
- invoice;
- guest portal;
- ops console;
- partner channel;
- AI answer.

## Step 5: Store Once

If the same fact is needed in several outputs, store it once in the right core
and let the experience engine compile the outputs.
