# 3. Booking & Journey Core

This core contains one timeline for each customer journey.

Available data:

- inquiry;
- booking;
- travelers;
- payments;
- pickup and drop-off;
- health requirements;
- documents;
- lifecycle status;
- website checkout intake flow;
- sanitized customer portal booking details.

Still missing as actual history:

- qualification records;
- quotation revisions;
- communication log;
- review request lifecycle.

This core should eventually be database-backed because it contains dynamic
customer and booking state.
