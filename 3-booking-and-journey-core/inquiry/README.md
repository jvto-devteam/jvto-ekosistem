# Inquiry

This folder contains the structured website tour-detail to checkout intake flow.
It does not contain historical pre-booking inquiry conversations.

Available data:

- `website-tour-to-checkout-flow.json`

Current coverage:

- tour detail inputs before checkout;
- add-on selection rules;
- checkout detail/contact fields;
- ISIC conditional verification;
- payment/deposit logic;
- legacy checkout payload contract.

Still not available:

- historical WhatsApp/email pre-booking inquiry records;
- prospect qualification status before checkout;
- abandoned checkout sessions.
