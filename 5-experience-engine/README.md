# 5. Experience Engine

This is the output layer.

It should read from the other four cores and produce:

- public website;
- SEO metadata;
- JSON-LD;
- knowledge feed;
- WhatsApp messages;
- email templates;
- quotation and invoice output;
- guest portal;
- ops console;
- partner feed;
- AI answers.

This folder should not become a new source of truth. It adapts and compiles data
from the cores.
