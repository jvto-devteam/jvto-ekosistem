# WhatsApp Messages

This folder now contains structured WhatsApp automation templates extracted from
JVTO checkout, Xendit webhook, trip reminder, media follow-up, Bali transport,
hotel reservation, and crew reminder code.

Available data:

- `automated-message-templates.json`

Current coverage:

- customer pending-payment and confirmed-payment messages;
- balance payment reminder;
- trip information reminder;
- trip media/review request;
- internal ops, hotel partner, Bali transport, and crew reminders.

Not stored here:

- sent-message logs;
- real customer names, phones, booking URLs, payment links, group IDs, or API keys.
