# Analytics

This folder contains aggregated analytics outputs generated from existing
booking, payment, traveler, readiness, and partner-channel summaries.

Available data:

- `booking-channel-payment-readiness-summary.json`
- `google-review-insights.json`
- `profitability-summary.json`

Current coverage:

- channel mix;
- duration mix;
- pax distribution;
- top package usage;
- readiness exceptions;
- payment settlement and balance snapshot.
- profit and profit margin by channel/package using backoffice profit values.
- invoice-minus-expense comparison values for audit/explainability.
- Google review rating, star distribution, review themes, crew mentions, and
  package-linked review coverage.
- Google review media coverage from public user-contributed review media.
- Google crew review-count reconciliation using canonical crew aliases plus
  unresolved name detection.
- Crew featured-review evidence, including selected Google review media and
  traceable original review/source links.

Still not available:

- full inquiry-to-booking funnel;
- quotation conversion;
- review-request conversion;
- detailed commission, payment fee, refund, credit, and overpayment breakdowns
  if JVTO wants to explain the existing backoffice profit value.
