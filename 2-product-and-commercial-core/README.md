# 2. Product & Commercial Core

This core contains one canonical definition for what JVTO sells.

Available data:

- tour product IDs;
- routes and duration;
- itinerary versions;
- inclusions and exclusions;
- pricing rules;
- deposit rules;
- add-ons;
- luggage and pax rules;
- health requirements;
- cancellation and credit rules;
- channel availability.

This core is filled from product contracts, package details, itinerary core
datasets, pricing/add-on rules, and customer-portal itinerary observations. It
should continue to represent what JVTO sells, not free-form website prose.
