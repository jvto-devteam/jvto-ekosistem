# 4. Operations Core

This core contains execution readiness and internal operating state.

Expected data:

- trip readiness;
- missing data;
- crew assignment;
- vehicle assignment;
- hotel and partner confirmation;
- health certificate status;
- pickup confirmation;
- closure and plan-B;
- incident log;
- operational events.
- expense management.

This core should eventually be database-backed because operational state changes
per trip.
